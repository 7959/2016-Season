Gamepad 1:
	Left joystick: Movement
	Left bumper: Rotate left
	Right bumper: Rotate right
	D-Pad left: Retract poker
	D-Pad right: Extend poker
	Start: If Gamepad 2's start button is also pressed, save and end the OpMode.
Gamepad 2:
	X: Hold to Reload
	A: Shoot
	B: Press slightly after each shoot to allow reloading
	D-Pad up: Aim launcher upwards
	D-Pad down: Aim launcher downwards
	Start: If Gamepad 1's start button is also pressed, save and end the OpMode.
During init:
	Gamepad 1:
		D-Pad up: Increase letter
		D-Pad down: Decrease letter
		D-Pad left: Move index left
		D-Pad right: Move index right
